Le nom, le déterminant et l'adjectif

Le nom

Le nom est le noyau du groupe nominal. Il a un genre (masculin ou féminin) et un nombre (singulier ou pluriel).

Communprécédé d'un déterminant : une rose
Proprecommence par une majuscule : Rose
Animéun être vivant, personne ou animal : une fourmi
Non animéune chose : un fauteuil
Concretperçu par les sens : une table
Abstraitune idée, un sentiment : le courage

Le déterminant

Le déterminant se place avant le nom. Il fait partie du groupe nominal.

Articles définisle, la, les, l'
Articles indéfinisun, une, des
Démonstratifsce, cet, cette, ces
Possessifsmon, ma, mes
ton, ta, tes
son, sa, ses
notre, votre, leur
nos, vos, leurs
cet s'emploie devant un nom masculin qui commence par une voyelle ou un h muet : cet arbre, cet homme.
Devant un nom féminin qui commence par une voyelle, on dit mon, ton, son : mon amie, son école.

L'adjectif

L'adjectif apporte des précisions sur le nom ou le pronom auquel il se rapporte. Dans le groupe nominal, il est placé devant ou derrière le nom : Alexandre est un beau garçon blond.

Il s'accorde en genre et en nombre avec le nom ou le pronom : un sorcier malveillant → des sorcières malveillantes.

Épithètedans le groupe nominal, à côté du nom : une robe violette
Attributaprès un verbe attributif : la robe est violette
Verbes attributifs : être, paraître, sembler, avoir l'air, demeurer, rester, devenir…
